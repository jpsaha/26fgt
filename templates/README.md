# Templates

Reusable Typst presentation and layout logic.

This directory contains the Typst templates, macros, styles, theorem environments,
navigation components, mathematical notation, colors, counters, and other reusable
presentation machinery.

## Contents

- `blocks.typ` — reusable content blocks
- `theorems.typ` — theorem-like environments
- `pdflayout.typ` — PDF layout
- `render.typ` — rendering helpers
- `nav.typ` — navigation
- `math/` — mathematical notation and utilities
- `euler/` — Euler-style components and styles

## Principle

Templates define **how content is presented**, not what the mathematical content is.

Changes here may affect multiple courses, lectures, or generated outputs.
